# サードパーティ ライセンス

DesktopMate は、VRM/GLB の 3D 描画に以下のオープンソースライブラリを利用し、
その JavaScript を `Sources/DesktopMate/Resources/bundle.js` に同梱（バンドル）しています。
いずれも MIT ライセンスです。配布時は本ファイルを同梱してください。

## 注意: キャラクターモデル / 画像について

- 本アプリ本体には、既定のキャラクター画像は同梱していません（既定は図形描画）。
- ユーザーが読み込む VRM / GLB / 画像は各ファイルの配布・利用条件に従ってください。
  他者が作成したモデルやキャラクター画像を同梱して再配布する場合は、その作者の
  ライセンス（改変・再配布の可否など）を必ず確認してください。
